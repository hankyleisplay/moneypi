## 功能

**資產與投資**
- 存款、現金、股票、ETF、基金、貸款（負債）一次管理，多幣別（TWD、USD、JPY、EUR、CNY、HKD）自動換算成台幣。
- **持倉**：記錄買入、賣出、配息，自動用平均成本法算出持有數量、平均成本、總成本、未實現／已實現損益、累計配息與總報酬。
- **年化報酬率 (XIRR)**：依每一筆交易的真實日期計算（交易跨度滿 90 天才顯示）。
- **補登舊持倉**：把日期改成當初買進那天，按「帶入這天的收盤價」，就能用當時的價格算出真實損益。
- **定期定額**：設定每月金額與扣款日，自動依當天收盤價記成買入交易；開始日期可填過去，會自動補上之前每一期。
- **資金來源**：買賣時可選擇動用 App 內的某個存款（自動扣款、賣出與配息則加回，刪除交易會還原），或視為外部資金。
- **股價與匯率自動同步**（Yahoo Finance）：台股只要填代號，上市上櫃自動辨識。
- **配息自動記錄**：依除息日前你持有的股數，自動記下稅前配息（可選入帳到哪個存款；刪除後不會補回）。
- **價格走勢與預測**：歷史收盤價、你的平均成本線與買賣點，並以歷史趨勢外推一年（統計外推，非預測保證）。

**目標與記帳**
- 可建立多個目標（財富自由、買車…），看總淨資產或指定項目；依你資產成長的速度預估何時達成。
- 收支記帳與每月統計。
- **月報**：每月淨資產變化、記帳結餘、投資買賣與配息、各目標進度與預估達成時間。
- 總覽：淨資產走勢、資產配置、投資組合。

**手機與同步**
- **區域網路**：電腦和手機在同一個 Wi-Fi，掃描 QR Code 即可在手機瀏覽器使用，可安裝成手機桌面應用（PWA）。
- **遠端**：用 Cloudflare 臨時隧道，在外面用行動數據也能連回電腦。每次開啟都是新網址與一次性密鑰，關閉即失效；cloudflared 由 MoneyPi 詢問後自動下載並核對官方校驗碼（沒有 winget 也可以，也可手動安裝）。

**其他**
- **密碼保護**：可設定密碼，資料檔以 Argon2id + XChaCha20-Poly1305 加密；忘記密碼無法救回。
- **每日自動備份**：複製到你指定的資料夾（例如 OneDrive），保留最近幾份；設了密碼則備份也是加密的。
- 內建**導覽與說明**：首次開啟互動導覽、名詞旁的「?」提示、完整教學。
- 簽章的**自動更新**。
- 備份與還原、CSV 匯出匯入。
- Liquid Glass 白色介面、果凍動畫。
- **省電模式**：一鍵關閉光暈、毛玻璃與動畫並降低背景檢查頻率；可設為「自動」，低電量時自動切換。

## 快速開始

1. 到 [Releases](https://github.com/hankyleisplay/moneypi/releases/latest) 下載 `MoneyPi_x.y.z_x64-setup.exe`（建議）或 `.msi`，安裝後開啟。
   - 安裝檔未經程式碼簽章，Windows SmartScreen 可能會提示，請選「更多資訊 → 仍要執行」。
2. 第一次開啟會有導覽；之後可按右上角「?」重看。
3. 左下「＋ 新增項目」先加存款與現金，再加股票／ETF（勾選「持倉」，台股填代號如 `0050`）。
4. 在項目詳情按「＋ 記錄交易」輸入買入，或設定「定期定額」。

### 新增股票／ETF 的成本要填哪裡？

- **建議用「記錄交易」**：每筆買入記日期、股數、成交價、手續費，成本、損益與年化報酬都會自動算出。
- 勾選「持倉」後不用填金額，因為 **現值 = 持有數量 × 現價**；只要記錄過任何一筆交易，數量與成本就完全由交易記錄計算。

## 資料與隱私

- 所有資料存在本機 `%APPDATA%\com.moneypi.app\moneypi.json`，**不會上傳到任何伺服器**。
- 只有這些情況會連網：向 Yahoo Finance 查股價／匯率與歷史收盤價、檢查更新（GitHub）、你主動開啟遠端連線時（資料會經過 Cloudflare）、你同意後下載 cloudflared。
- 區域網路同步用 PIN 保護（連續輸錯會暫時鎖定）；遠端連線只認該次隧道專屬的密鑰。
- 可在「設定 → 安全性」設定密碼，並在「自動備份」開啟每日備份；手動「匯出備份」產生的 JSON 是明文，請自行保管。

## 從原始碼建置

需要 [Rust](https://rustup.rs/)、[Node.js](https://nodejs.org/) 與 Windows 的 WebView2（Windows 10/11 內建）。

```bash
npm install
npx tauri dev      # 開發模式
npx tauri build    # 產生安裝檔（src-tauri/target/release/bundle）
```

單元測試：

```bash
cd src-tauri && cargo test
```

> 自動更新使用 Tauri updater 簽章。自行建置並發布更新時，需要設定自己的金鑰（`TAURI_SIGNING_PRIVATE_KEY`），並把 `src-tauri/tauri.conf.json` 裡的 `pubkey` 與更新網址換成自己的。

### 專案結構

| 路徑 | 說明 |
|---|---|
| `src/` | 前端（純 HTML / CSS / JavaScript，無打包步驟），也是手機網頁版 |
| `src-tauri/src/lib.rs` | Rust 後端：資料模型與計算、行情抓取、區域網路伺服器、遠端隧道、更新 |
| `src-tauri/tauri.conf.json` | 應用程式、安裝檔與更新設定 |
| `branding/` | 圖示原稿（SVG） |
