    手機連線

    讓手機、平板在同一個 Wi-Fi 下，用瀏覽器開啟 MoneyPi。資料仍存在這台電腦，兩邊即時同步。

    用手機相機掃描 QR Code 即可連線；或在手機瀏覽器輸入：

    連線為區網 HTTP（未加密），請只在可信任的網路使用。

    1. 手機與電腦要連同一個 Wi-Fi（不是訪客網路，也不是行動數據）。
    2. 電腦上的 MoneyPi 要保持開啟。
    3. 第一次啟用時 Windows 防火牆會詢問，請按「允許」。若曾按過取消，到「Windows 安全性 → 防火牆 → 允許應用程式通過防火牆」勾選 MoneyPi。
    4. 部分路由器開啟「AP 隔離」會擋住裝置互連，請在路由器關閉。
    5. 有多個網路位址時，請試試上面列出的每一個。
    6. iPhone：用 Safari 開啟後，按分享 → 加入主畫面，就像 App 一樣使用。Android：Chrome 選單 → 加到主畫面。

    用 Cloudflare 臨時隧道，讓手機在外面用行動數據也能連回這台電腦，不需要同一個 Wi-Fi。

    輸入同步 PIN

    請輸入電腦上 MoneyPi「設定」裡顯示的 PIN。
