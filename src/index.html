    說明與教學

    快速開始：4 個步驟
    1. 按左下「＋ 新增項目」，先把存款、現金加進來：類別選「銀行存款」或「現金」，金額填目前餘額。
    2. 要加股票、ETF、基金：同樣「＋ 新增項目」，類別選「股票」或「基金/ETF」，勾選「持倉」。台股「行情來源」選「台灣」並填代號（例如 0050、2330），數量與成本先留空。
    3. 點進那個項目，按「＋ 記錄交易」輸入買入（日期、股數、成交價、手續費）。每月固定買入的，改用下面的「定期定額」。
    4. 到總覽設定目標，MoneyPi 會依你資產成長的速度預估何時達成。
    新增股票／ETF 時，成本要填在哪？

    建議用「記錄交易」：每一筆買入都記日期、股數、成交價、手續費，MoneyPi 會自動算出持有數量、平均成本、總成本，也才算得出年化報酬率。

    之前就買了、忘了當時價格？記錄交易時把日期改成買進那天，按「帶入這天的收盤價」就會填入當時的收盤價（實際成交價請以券商對帳單為準）。

    勾選「持倉」後，新增視窗裡的「金額」欄會消失，因為現值 = 持有數量 × 現價，由程式自己算。只要記錄過任何一筆交易，數量與成本就完全由交易記錄計算，新增視窗裡的「總成本」欄不再採用。

    畫面上的數字是什麼意思？
    現值（頁面最上面的大數字）
    持有數量 × 現價，現在值多少錢，會隨股價變動。總資產加的是現值。
    總成本／平均成本
    你實際花的錢（含手續費）。平均成本 = 總成本 ÷ 持有數量。
    未實現損益
    現值 − 總成本。還沒賣掉，所以只是帳面賺賠。
    已實現損益
    已經賣出的部分實際賺賠多少。
    累計配息
    你記錄的配息總額，計入總報酬。
    年化報酬率 (XIRR)
    依真實買賣日期，換算成一年約賺賠幾 %。交易跨度滿 90 天才顯示。
    淨資產
    總資產 − 總負債。

    頁面上有 ? 的名詞，點一下就會看到解釋。

    定期定額怎麼設定？

    進到那檔標的的詳細頁，往下找「定期定額」，按「＋ 新增定期定額」，填每期扣款金額、每月扣款日、手續費、開始日期。

    每期會自動記成一筆買入，價格是扣款日當天（或之後第一個交易日）的收盤價。開始日期可以填過去，之前每一期會自動補上。

    扣款金額包含手續費，台股勾選「只買整股」會把零頭捨去。手續費不確定可先填 1（台股零股最低 1 元）或留空。

    「資金來源」要選哪一個？

    選存款項目：買入時 MoneyPi 會自動從那個存款扣錢（賣出、配息則加回去），總資產不會因為買股票而重複計算。

    選外部資金：不動 App 內的存款。如果你的存款餘額是「已經扣過買股票的錢」的現況，請選這個，才不會重複扣。

    刪除一筆交易時，被扣的存款會自動還回去。

    月報、密碼與自動備份

    月報：左邊「月報」看每個月的淨資產變化、記帳結餘、投資買賣與配息、各目標進度。記帳越完整，「估計投資與其他變動」越準。

    密碼：「設定 → 安全性」可設定密碼，資料檔會加密儲存，每次開啟都要輸入。忘記密碼無法救回資料。右上角的鎖頭可以立即鎖定。

    自動備份：「設定 → 自動備份」開啟後，每天複製一份資料檔到你指定的資料夾（例如 OneDrive），保留最近幾份。設了密碼的話，備份也是加密的，還原時需要輸入當時的密碼。

    電腦很慢或想省電？

    「設定 → 效能模式」選省電：關掉背景光暈、毛玻璃模糊和所有動畫（果凍效果、進場動畫），並降低背景檢查頻率，CPU／GPU 與耗電會明顯下降，功能完全一樣。

    自動：筆電沒插電且電量 30% 以下，或系統關閉了動畫效果時，自動切換成省電；標準則維持完整特效。這個設定每台裝置各自記住（電腦和手機可以不同）。

    配息會自動記錄嗎？

    有設定行情代號的持倉，MoneyPi 會依除息日前你持有的股數，自動記下配息（稅前每股配息 × 股數）。刪除自動記下的配息後不會再補回來。想關閉可在編輯項目時取消「自動記錄配息」，也可以選配息要入帳到哪個存款。

    目標與預估達成時間

    目標可以有很多個（財富自由、買車…），可以看總淨資產，也可以只算指定的幾個項目。

    預估時間是依你最近資產成長的速度推算的，需要累積幾天的紀錄才算得出來；填了目標日期，還會告訴你趕不趕得上。

    價格走勢與預測可信嗎？

    走勢圖的預測是用過去價格畫一條趨勢線往後延伸，淡色帶是歷史波動範圍。這只是統計外推，不是預測保證，也不構成投資建議。趨勢吻合度（R²）越低，參考性越低。

    手機連線（區域網路／遠端）

    區域網路：電腦和手機在同一個 Wi-Fi，掃描 QR Code 即可。遠端：不限網路，需要 cloudflared 工具，MoneyPi 會詢問並協助安裝；每次開啟都是新網址與新密鑰，請用 QR Code 或「複製連結」，只輸入網址無法連線。

    常見問題
    股價沒更新？
    確認項目有填代號與行情來源，再按上方「同步股價與匯率」。
    為什麼沒有年化報酬率？
    需要有買入記錄，且從第一筆到現在滿 90 天。
    怎麼備份？
    「設定 → 備份與還原」。重要資料請定期備份。
    資料存在哪？
    只存在你的電腦（%APPDATA%\com.moneypi.app），不會上傳。使用遠端連線時資料才會暫時經過 Cloudflare。

    手機連線

    讓手機、平板在同一個 Wi-Fi 下，用瀏覽器開啟 MoneyPi。資料仍存在這台電腦，兩邊即時同步。

    用手機相機掃描 QR Code 即可連線；或在手機瀏覽器輸入：

    連線為區網 HTTP（未加密），請只在可信任的網路使用。

    1. 手機與電腦要連同一個 Wi-Fi（不是訪客網路，也不是行動數據）。
    2. 電腦上的 MoneyPi 要保持開啟。
    3. 第一次啟用時 Windows 防火牆會詢問，請按「允許」。若曾按過取消，到「Windows 安全性 → 防火牆 → 允許應用程式通過防火牆」勾選 MoneyPi。
    4. 部分路由器開啟「AP 隔離」會擋住裝置互連，請在路由器關閉。
    5. 有多個網路位址時，請試試上面列出的每一個。
    6. iPhone：用 Safari 開啟後，按分享 → 加入主畫面，就像 App 一樣使用。Android：Chrome 選單 → 加到主畫面。

    用 Cloudflare 臨時隧道，讓手機在外面用行動數據也能連回這台電腦，不需要同一個 Wi-Fi。

    輸入同步 PIN

    請輸入電腦上 MoneyPi「設定」裡顯示的 PIN。
