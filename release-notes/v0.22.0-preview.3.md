## MoneyPi v0.22.0-preview.3（預覽版）

第三個預覽版：MoneyPi 電腦版第一次有 **macOS** 和 **Linux** 版本。功能和 Windows 版相同（包含 preview.1、preview.2 的所有新功能）。

### macOS（Intel 與 Apple 晶片通用）
- 下載 `.dmg`，打開後把 MoneyPi 拖進「應用程式」
- 程式沒有經過 Apple 公證（需要付費的開發者帳號），第一次開啟會被擋下：到「系統設定 → 隱私權與安全性」，在下方按「強制打開」即可，之後就能正常開啟
- 之後的新版本會在 App 內提示，一鍵更新
- 手機連線第一次啟用時，Mac 會問「是否允許接受連入連線」，請按「允許」

### Linux（x86_64）
- `.AppImage`：加上執行權限（`chmod +x`）後直接開啟，**會自動更新**
- `.deb`：Ubuntu／Debian 用，需要手動下載新版更新
- 需要系統有 WebKitGTK 4.1（Ubuntu 22.04 以上、Debian 12 以上大多已內建）

### 跨平台調整
- 「遠端連線」需要的 cloudflared：Mac 和 Linux 也能自動下載官方版本並驗證校驗碼；Mac 也可以用 Homebrew（`brew install cloudflared`）安裝，App 會自動找到
- 「開啟備份資料夾」在 Mac（Finder）和 Linux（檔案管理員）也能用
- 綁定的手機上會顯示 Mac 的電腦名稱、Linux 的主機名稱（原本只會顯示「電腦」）
- 說明中的防火牆提示改成同時說明 Windows 和 Mac

### 限制
- macOS 與 Linux 版是在 GitHub 的雲端機器上建置的，**作者手邊沒有 Mac／Linux 電腦實測**，可能有平台特有的小問題，歡迎回報
- Linux 只提供 x86_64（一般電腦）版本
