## MoneyPi v0.21.1

### 手機版會提醒你有新版本了
- 手機 App 啟動時（之後每 6 小時一次）會到 GitHub 查有沒有更新的版本。有的話，上方會出現「發現新版本 vX.Y.Z」，按「下載新版」就用瀏覽器下載新的 APK，下載完成後點開安裝即可，資料會保留
- 也可以到「設定 → 版本 → 檢查更新」手動檢查；已是最新版、沒網路時都會用白話說明
- Android 不允許 App 自己靜默安裝，所以下載後還是要你點一下安裝（第一次可能需要允許「安裝未知來源的應用程式」）。這和電腦版「一鍵更新並重新啟動」不同
- 只有這個專案自己發布的 APK 連結才能被開啟；檢查更新只是一般的網路請求，不會送出你的資料。新版剛發布、APK 還沒上傳完成時不會提醒，等幾分鐘就會出現
- 「說明與教學」的手機版說明新增「更新」一段

### 預覽版頻道（電腦與手機都有）
- 「設定 → 版本 → 更新頻道」可以選「穩定版」（預設，只收到正式發布的版本）或「預覽版」（提早試用新功能，可能還有沒修好的問題）。切到預覽版前會先說明風險；這個選項只影響這台裝置，不會同步，也不會被還原備份蓋掉
- 選了預覽版，有新的預覽版或新的穩定版都會提醒；預覽版會標示「（預覽版）」。切回穩定版不會自動降版，想退回舊版需要重新安裝（先匯出備份）
- 預覽版的版本號寫成 `0.22.0-preview.1`：它永遠比同號的正式版舊、比上一個正式版新。預覽版以 GitHub 的「預先發行版」發布，電腦版只提供 `x64-setup.exe` 安裝檔；沒選預覽版的人不會被推送，GitHub 的「最新版本」與穩定版自動更新也都不受影響
- 手機 APK 的內部版本號（versionCode）改成「每次發布都遞增、正式版一定高於它的預覽版」的算法（正式版 0.21.1 = 2100199），之後預覽版與正式版可以互相覆蓋更新

### 注意
- 已安裝 v0.21.0 或更早版本的手機，這一版需要手動下載安裝一次（因為舊版還沒有這個功能）；裝好之後，以後就會收到提醒

### 電腦版
- 沒有功能變更（版本號與手機版同步），電腦版沿用原本的自動更新

### 手機點按鈕不再閃藍色框框
- 修正手機版點按鈕、項目時會先閃一下藍色方框（Android 預設的點擊高亮），看起來像在用手機瀏覽電腦版網站。現在點擊沒有藍框，也不會再有雙擊縮放的延遲，按鈕不會被選取成文字，觸控後也不會卡在「滑鼠移上去」的放大狀態
