## MoneyPi v0.17.0

### 「每月淨資產變化」改成更容易看懂
- 原本的長條圖只畫出「變化量」，看不出是相對於什麼、也不知道實際金額，而且數字常和月份標籤疊在一起
- 現在每個月一列（最新的月份在最上面）：往右的綠色長條代表比上個月底**增加**，往左的紅色長條代表**減少**
- 每列右側直接寫出變化金額與百分比（例如 `－13,832`、`－24.4%`）
- 每列下方列出這個變化的來源：`月底淨資產 上月 → 本月`，一眼看出是從多少變成多少
- 本月標示「截至今天」；開啟「隱藏金額」時，金額與淨資產都會一併隱藏
- 手機視窗寬度下也能完整顯示

### 發布流程
- 之後的版本改由 GitHub Actions 自動建置、簽章與發布，並會在發布前檢查安裝檔、簽章與 `latest.json` 是否齊全
